# 模型选择与成本说明

## 当前推荐

第一版 LLM 增强默认使用 DeepSeek `deepseek-chat`。

选择理由：

- 中文标题改写和摘要能力够用。
- API 形态接近 OpenAI，接入简单。
- 价格适合每日自动化简报这类低频任务。
- 对 Top 20 新闻做增强时，整体成本很低。

## DeepSeek 价格

按 DeepSeek 官方 API 文档，`deepseek-chat` 价格为：

- 输入 cache hit：`$0.07 / 100万 tokens`
- 输入 cache miss：`$0.27 / 100万 tokens`
- 输出：`$1.10 / 100万 tokens`

官方价格页：<https://api-docs.deepseek.com/quick_start/pricing-details-usd>

本项目每天只处理 Top 20 条新闻，预计每天成本约 `$0.01 - $0.03`，每月约 `$0.3 - $1`，折合人民币约 `2 - 8 元`。价格可能变化，生产使用前应以官方页面为准。

## 为什么不用 reasoner

`deepseek-reasoner` 更适合复杂推理、数学、代码分析等任务。本项目第一阶段主要做：

- 中文标题优化
- 核心内容提炼
- 原文摘录中文大意
- 为什么值得关注

这些任务用 `deepseek-chat` 更划算。

## 国内外模型对比

| 模型 / 服务 | 适合场景 | 当前建议 |
| --- | --- | --- |
| DeepSeek | 中文摘要、标题改写、低成本自动化 | 默认推荐 |
| Qwen / 通义千问 | 国内云生态、中文任务、可选低价模型 | 后续可配置 |
| Kimi | 长文本中文阅读和总结 | 成本单独评估 |
| OpenAI | 稳定通用质量、国际服务 | 作为高质量备选 |
| Gemini Flash / Flash-Lite | 国际低价、多模态和长上下文 | 后续 provider 扩展 |

第一版不同时调用多个模型，以免增加成本和维护复杂度。当前代码优先支持 OpenAI-compatible HTTP 接口，后续可以通过 `config/llm.yml` 切换兼容服务的 `base_url`、`model` 和 API Key 环境变量。

## 成本控制原则

- 只对 Top 20 新闻调用模型。
- 不总结全部抓取结果。
- 限制每条新闻输入摘要长度。
- 限制模型输出长度。
- 单条失败只回退该条，不影响整份简报。
- 没有 API Key 时自动使用规则版输出。

## 输出边界

模型只负责改善可读性，不负责替代事实判断。Markdown 中必须继续保留：

- 原文链接
- 原始标题
- 来源名称
- 来源等级
- 发布时间
- 规则分数
- 命中关键词

社区讨论和早期信号仍不能因为模型总结而变成事实确认。
