### 7. A Benchmark and Diagnostic Study of Epistemic Admission in Shared Agent Memory

- 来源等级：早期信号
- 来源名称：arXiv cs.AI
- 来源类型：RSS
- 发布时间：2026-09-29 12:00
- 原文链接：https://arxiv.org/abs/2609.30813
- 命中关键词：Agent、agents、benchmark、multi-agent

- 关键词召回分：28
- 规则召回分：38

- 模型分项： 新闻价值 6/10；个人相关性 8/10；可行动性 6/10；判断信心 5/10
- 模型中文标题：arXiv 论文提出 CPB 基准：评估共享 Agent 记忆中的声明准入与虚假信念传播
- 模型背景：多 Agent 系统常共享一个记忆库，Agent 可能把检索到的信念复制或改写后重新写入，导致重复声明被误当作独立证据，虚假信息随之扩散。该论文针对这一共享记忆的准入判定问题提出评测基准。
- 模型核心摘要：论文提出 Correlated Promotion Benchmark（CPB），包含基于公开标注数据、固定金标准的 CPB-Static，以及让多 Agent 团队在共享存储上运行、记录全部读写与来源谱系的 CPB-Live，并由独立消费者仅凭存储作答。作者在四个 Agent 家族上评测八种准入策略，发现去重来源的策略会误拒大量真实声明，而保留答案覆盖的策略几乎与无限制共享一样多地接纳虚假声明。
- 模型证据说明：原文给出量化结果：按声明来源类型门控可将虚假采纳率降至 0.06–0.09，而其他作答策略为 0.22–0.47；但摘要未给出完整实验规模与复现细节。
