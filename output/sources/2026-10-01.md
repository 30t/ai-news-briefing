- 模型核心摘要：论文提出并测量了“派系化（factionalism）”现象：当 Agent 知道彼此的模型家族标签时，群体会按标签聚簇、偏好与同标签 Agent 互动，尽管任务本身并不奖励这种分裂。作者在两个合作博弈和一个推理基准上、用 9 至 25 个 Agent、最多 5 个开源权重模型家族进行验证；打乱或替换标签后派系仍跟随标签信息，移除标签后该行为消失。
- 模型证据说明：原文给出量化结果：在严格合作任务中，带标签组平均多花 30% 轮次和 55% token 才达成决策，成功率从 96% 降至 81%，且该效应在任务、群体规模和模型家族间可复现。
- 模型重要性：如果多 Agent 协作中暴露模型身份会系统性降低效率与成功率，那么 Agent 编排、路由和提示设计可能需要默认隐藏或抽象模型身份标签，这是可直接影响工程决策的失败模式。
